Backup and shared configuration

Organisation configuration bundle

This is the shared, server-side organisation layer stored under config/org/. Export creates a portable, versioned bundle. Import validates and replaces that organisation layer; it does not change master YAML or projects.

Browser-only settings backup

These browser-local admin overrides contain local AI settings, custom phases, and edited rules saved only in this browser. This separate backup does not include the organisation bundle or projects. It does not include projects or change master YAML.
